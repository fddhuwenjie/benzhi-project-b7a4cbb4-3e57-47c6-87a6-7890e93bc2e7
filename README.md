# 字幕发布工作台

`caption-release-workbench` 面向公共广播无障碍制作团队，将节目素材基线、字幕时间轴、可访问性检查、人工审校、问题整改、定向复验和冻结发布纳入一条可追溯流程。服务由 Go 提供原生浏览器页面和同源 JSON API，业务数据、幂等结果及只追加审计事件保存在本地 SQLite。

## 构建

```bash
go build -o captionflow ./cmd/captionflow
```

## 运行

```bash
go run ./cmd/captionflow -addr=127.0.0.1:19081
```

默认访问地址为 `http://127.0.0.1:19081`，默认数据库文件为当前目录的 `captionflow.db`。可用 `-db=/path/to/captionflow.db` 指定数据库。服务只接受回环监听地址；也可将 `PORT` 设置为端口号，此时监听 `127.0.0.1:<PORT>`。显式 `-addr` 的优先级高于 `PORT`。

浏览器工作台提供按状态、语言、责任人和实时风险组合筛选的节目队列，并支持按风险、严重问题数量和更新时间排列待办。时间轴可按正文、说话人、声音说明及毫秒区间检索，命中项会携带前后字幕上下文和当前修订标记。草稿或整改中的字幕段可按正文断点和毫秒位置先做不落库拆分预检，确认后在同一修订事务中保留前半段标识、生成后半段标识、重排时间轴，并清除已过期的规则结果和整改证据。

时间轴恰好选择两个相邻字幕段时可先预览再合并；预览会校验时间边界、正文和审校问题引用，遇到说话人冲突要求明确合并说话人。确认携带预览修订、确认令牌和请求幂等标识，在同一事务中保留首段 ID、换行拼接正文与声音说明、递增修订并记录 `cues.merged` 审计事件。

问题审校面板支持按状态、严重级别、规则分类、字幕段和描述关键词组合筛选，可按严重级别、字幕时间或最近复验时间稳定排序。清单同时展示各维度数量、涉及字幕段数、无证据和证据失效数量；每项可定位回现有时间轴。查询响应携带项目修订，发现并发变化时会提示刷新并禁用旧清单上的批量操作。规则检查中的失败项仍可整批转为带来源运行和检查修订的审校问题；整改后可查看登记字幕版本到整改版本的正文、时间、说话人和声音说明差异，证据过期会阻止复验。

整改状态可从修订历史选择早于当前版本的字幕快照，先查看按字幕段和字段列出的差异，再以确认令牌回滚；回滚会生成新的项目修订、清空当前规则结果并使既有整改证据失效，来源修订和差异摘要写入审计。定向复验前可查询证据批次汇总，系统逐项校验报告与整改快照并按时间轴返回有效、缺失、失效及阻塞原因；汇总绑定 `expected_revision`，项目并发更新后不会允许据此批量复验。

发布与审计视图支持人员、事件、时间和游标分页，事件详情包含 `request_id`、操作类型、项目修订和关联对象，并可继续查看对应修订差异或发布清单完整性。素材校验值使用 64 位 SHA-256 十六进制摘要，系统统一转为小写并通过 SQLite 唯一约束拦截重复素材。所有写请求均携带 `request_id` 与 `expected_revision`，分别用于幂等重放和并发冲突检测。

发布负责人需要先查询或在工作台加载当前发布预检，再携带预检中的 `current_revision`、`caption_checksum` 和 `confirmation_token` 批准冻结。发布后查询清单会同时返回字幕摘要、素材基线、冻结修订、清单版本和批准审计的逐项完整性报告；复核失败不会解除项目只读状态。冻结核验包摘要会从清单指向的修订快照重新核对字幕结构、数量、两类校验值、项目标识和批准审计，全部通过后才允许下载带项目标识及清单版本的确定性 JSON 文件；摘要与下载均不会改变项目修订或新增审计事件。

## 自检

```bash
go run ./cmd/captionflow -selfcheck -addr=127.0.0.1:19081
```

自检使用隔离临时数据库和真实回环 HTTP 请求，依次完成建档、字幕制作、规则检查、审校退回、修订整改、定向复验、发布预检、批准冻结、发布清单完整性复核及审计查询，随后主动关闭服务并退出。

## 测试

```bash
go test ./...
```

测试覆盖素材摘要格式、字幕时间轴与批量偏移原子性、风险分层、上下文检索、规则失败转换、检查运行差异、批量问题重复拦截、整改证据字段差异与版本、完整审校发布状态机、稳定字幕校验值、SQLite 事务与幂等、乐观锁冲突、审计事件以及 HTTP 错误结构和监听配置。
